# Política de seguridad

No reportes una vulnerabilidad sospechada en un issue público, y no incluyas en
el reporte credenciales reales, videos de clientes ni contenido con copyright
de terceros.

Usá el reporte privado de vulnerabilidades de GitHub para este repositorio
cuando esté disponible. Incluí la versión o el commit afectado, el impacto, la
reproducción mínima y, si la conocés, una mitigación propuesta.

Los scripts de este repositorio corren localmente sobre el archivo o la URL que
le indiques: descargan con `yt-dlp` cuando el origen es una URL, y decodifican
con `ffmpeg`/`ffprobe`. Apuntalos solo a fuentes en las que confiés.

Claude Video Factory es un proyecto en etapa temprana. Lo que produce es
evidencia y clasificación para uso humano — no ejecuta ninguna acción
irreversible ni sube nada a ningún servicio de terceros.
